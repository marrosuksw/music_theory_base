# **Music theory base** 
## Summary:
The aim of this application is to provide a solid base of knowledge about different parts of music theory: notes, intervals, chords, scales and their different modes.
The main functionalities *will* include:
- finding scales for given notes and chords
- interactive circle of fifths wheel
- custom tabulature & chord progression notepad
## **Tech**:
### Backend
* ```Java``` + ```Spring Boot``` base
* ```JUnit 5``` for unit testing
* ```MySQL``` database for data storage
